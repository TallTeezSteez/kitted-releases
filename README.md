# Kitted downloads

Free gear checklists, a trip calculator and a camp menu.

## Download

- **Windows:** [Kitted-Setup.exe](https://github.com/TallTeezSteez/kitted-releases/releases/latest/download/Kitted-Setup.exe)

These links always get the newest version. Older versions: [all releases](https://github.com/TallTeezSteez/kitted-releases/releases).

**First time:**
1. Run the installer.
2. If Windows shows **"Windows protected your PC"**, click **More info**, then **Run anyway**. You only do this once.

Kitted updates itself after that.

More about Kitted, with screenshots: https://draftlineapps.com/kitted

## How a new version goes out

**Actions > Release > Run workflow.** Leave the version blank for the next number; add a line of "What's new" if you like. It builds and publishes on GitHub's free machines, and installed copies update themselves.

This repo is public so the downloads work for everyone. The app's code is in a private repo and isn't here.
